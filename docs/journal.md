# Journal

**Eine Zeile je Zug.** Datum, Hash, ein Satz, und — wenn es einen gab — der Fund.
Der ausfuehrliche Bericht steht in der Commit-Nachricht; sie ist an den Stand gebunden,
das Journal ist der Faden dazwischen.

Dieses Journal ersetzt seit `CLAUDE.md` §11 das Ergebnisdokument je Zug. Ein eigenes
Dokument entsteht nur noch auf Verlangen oder wenn ein Fund laenger ist als eine
Commit-Nachricht — eine Erhebung, eine Begutachtung, eine Messung mit Tafel.

Kennzahlen stehen **nicht** hier, sondern in [`kennzahlen.md`](kennzahlen.md).

**Fund** heisst: etwas, das ohne den Zug unbemerkt geblieben waere — ein falscher Wert im
Bestand, eine Route, die zu klein misst, eine Vorgabe, die ihren eigenen Zweck verfehlt.
Kein Fund ist auch eine Auskunft und wird als `—` geschrieben.
